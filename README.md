# ТЗ:

## ДЗ 1. Відрендерити багатомірний масив користувачів у React.

**Завдання:** Відрендерити багатомірний масив користувачів у React.

**Дані:** Використати масив з API (дані скопіювати в код, fetch не використовувати), або використати цей самий масив users, який знаходиться на GitHub.

**Папка проЄкту** з базовим підключенням бібліотек react, react-dom, babel зниходиться на GitHub.

**Вимоги:**
1. Відрендерити список користувачів.
2. Усі властивості кожного обʼєкта вивести у вигляді вкладених списків (ul > li).
3. Якщо властивість є:
    - примітивом (string, number) — вивести key: value
    - обʼєктом — рекурсивно вивести його властивості як вкладений список
4. Рендер має працювати для будь-якої глибини вкладеності.
5. Для кожного map обовʼязково використовувати key.
